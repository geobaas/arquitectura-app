01

Entrada

El API Gateway recibe la petición, autentica y limita la tasa. El Validador revisa el esquema y rechaza datos inválidos antes de gastar recursos.

02

Procesamiento

La Cola desacopla la recepción del trabajo. La Caché responde al instante si ya se calculó lo mismo; si no, el Worker ejecuta la lógica de negocio.

03

Salida

La Base de datos persiste el resultado, el Formateador lo serializa a JSON y la Respuesta lo devuelve al cliente con su código HTTP.
